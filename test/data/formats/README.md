# Sample formats

Unmodified copies of a few specifications from the official Kaitai Struct
formats repository (`kaitai-io/kaitai_struct_formats`, commit
`8d8353c5059e6cff0d9500313d6650000aab92c2`), used by the integration tests.
Each file keeps its own license, declared in its `meta/license` key
(CC0-1.0 or Unlicense).

They were chosen because they exercise a mix of rules, including real
key-order, indentation and encoding-name problems that `--fix` repairs.
