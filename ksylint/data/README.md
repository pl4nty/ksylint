# Vendored data

## `ksy_schema.json`

The official JSON Schema for `.ksy` files.

- Source: https://github.com/kaitai-io/ksy_schema (`ksy_schema.json`)
- Commit: `959e6f782179cb614a41b2beeec15153ed136b3c` (2025-08-14)
- License: see the upstream repository (CC0-1.0)
- Links to upstream issues/PRs in `$comment` strings are replaced with plain
  text ("kaitai_struct upstream issue N") by the update script.

Do not edit this file by hand. Refresh it with:

```sh
python scripts/update_schema.py            # latest master
python scripts/update_schema.py --ref <sha>  # a specific commit
```

The script rewrites this README with the new commit hash.

Small, documented corrections that ksylint applies on top of the vendored
schema at load time (for keys that the current compiler accepts but the
schema does not yet describe) live in `ksylint/schema.py` (`SCHEMA_PATCHES`).
